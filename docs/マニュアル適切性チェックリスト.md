# 院内マニュアル適切性チェックリスト

本チェックリストは、院内マニュアル（手順・基準・チェックリスト等）が「院内マニュアル管理：最低限の強制ルール」に準拠しているかを確認するためのものです。
運用に合わせて、**「A. 提出時（持ち込み時）チェックリスト」**と**「B. 登録・公開時チェックリスト」**の2段階で確認を行ってください。

---

## A. 提出時（持ち込み時）チェックリスト
**【対象者：マニュアルの作成者・Primary Owner】**
マニュアルを新規作成・改訂し、情報企画課（または管理部門）へ提出する前に確認してください。
※「管理番号」および「版（バージョン）」は情報企画課で付与・管理するため、提出時には空白または仮の状態で構いません。

### 1. ファイル形式と作成方針
- [ ] (任意) 可能な限り、将来のAI利活用を見据えて **Markdown方式** で作成している。
- [ ] (任意) pptx / ppt / xlsx / xls形式の使用は極力避けている。（やむを得ず使用する場合は、その理由を情報企画課に説明できる状態である）

### 2. メタ情報の記載（必須要件）
マニュアルの本文内（表紙やヘッダー等）に、以下の情報が明記されている。（管理番号と版は情報企画課が後で追記します）
- [ ] 制定日（新規の場合）または最終改訂日
- [ ] 次回レビュー期限（※最長でも5年以内の期限が設定されていること）

### 3. 役割と責任（Owner構造）の明記
- [ ] **Owner（存続責任）** が設定されている。（原則は「委員会」。適切な委員会がない場合に限り「部門」）
- [ ] **Primary Owner（実務責任）** が「個人」で設定されている。
- [ ] **Reviewer（定期確認責任）** が「個人（期限付き）」で設定されている。

### 4. 提出時のファイル・データ要件
- [ ] 提出する草案・作業用ファイルの名前は、マニュアル名が明確にわかるものにしている。（情報企画課で所定の命名規則に変更します）
- [ ] ファイル名に半角スペース、機種依存文字、システム予約記号（`\ / : * ? " < > |` など）が含まれていない。
- [ ] （統計表を含む場合のみ）「統計表における機械判読可能なデータ作成に関する表記方法」に従って作成されている。

---

## B. 登録・公開時チェックリスト
**【対象者：情報企画課・マニュアル管理担当者】**
提出されたマニュアル草案を審査し、正本PDFとして正式に登録・公開する際に確認してください。

### 1. 形式・要件レビュー
- [ ] 「A. 提出時（持ち込み時）チェックリスト」の必須要件（メタ情報、Owner構造など）をすべて満たしていることを確認した。
- [ ] 他の既存マニュアルと内容の整合性が取れている（矛盾がない）。必要に応じて、提出者や関連マニュアルのOwnerと調整を行った。

### 2. 管理番号・版の付与と正本化（PDF変換）
- [ ] 情報企画課にて、当該マニュアルに **「管理番号」** と **「版（バージョン）」** を採番・付与した。
- [ ] 本文内（表紙やヘッダー等）に、付与した管理番号と版が正しく追記・反映されている。
- [ ] 提出されたファイルから、情報企画課にて **正本PDF** への変換を行った。
- [ ] （Markdown以外で提出された場合）情報企画課にて、自動変換等により将来のAI利活用に向けた **Markdown版** を作成した。

### 3. 保管・登録と承認プロセス
- [ ] 最終的な正本PDFのファイル名が所定の命名規則（**`[管理番号]_[マニュアル名]_v[版数].pdf`**）になっている。
- [ ] 正本PDFを、所定の正式な **保管場所（公開用フォルダ・システム等）** に保存・登録した。
- [ ] 編集可能形式のファイル（草案・作業用）は、運用・教育の根拠とならないよう、正本とは別の適切な場所に保管した。
- [ ] 情報企画課としての **承認記録（承認日・承認者・版）** をシステムや管理簿等に記録した。
- [ ] 承認・登録完了後、院内への周知（公開）手続きを行った。

---

## C. 【運用フェーズ・特殊状況における確認事項】
マニュアルの公開後、以下の状況に該当する場合はチェックを行ってください。

- [ ] **期限外レビューの要否**：法令改正、関連ガイドライン改訂、機器更新、重大インシデント等が発生した場合は、設定期限に関わらず即時レビューを実施したか。
- [ ] **Primary Owner不在時の対応**：異動・退職等でPrimary Ownerが不在となった場合、「暫定有効（Primary Owner不在）」の注意表示を付しているか。（※不在から最大6か月で失効となるため、速やかに後任を設定すること）
- [ ] **失効マニュアルの扱い**：失効したマニュアルを運用や教育の根拠として使用していないか。（検索結果の「失効」表示、履歴保管の確認）
